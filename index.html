MoodMatch

Mood-Based Movie Recommendation Website

MoodMatch recommends movies based on mood and available time with a clean, responsive interface.

Live Preview → View Source

The idea

Choosing a movie can be surprisingly difficult — moods change, and time is often limited. MoodMatch narrows the decision down instead of scrolling endlessly.

How it works

Choose Mood ↓ Choose Available Time ↓ Recommendation Logic ↓ Movie Recommendation

Key features

  • Mood-based recommendations
  • Time-based recommendations
  • Responsive interface
  • Interactive UI
  • User-friendly design

What I learned

  • Writing JavaScript logic for recommendation rules
  • DOM manipulation and handling user interaction
  • Structuring a small frontend project from scratch
  • Designing a responsive, user-friendly interface
  • Debugging real problems as the app grew

DirectCollab

Creator × Brand Collaboration Platform

DirectCollab connects creators and brands directly, cutting out the back-and-forth of cold emails and manual outreach with a platform built specifically for collaboration matching.

The idea

Creators and brands both want to collaborate, but finding the right match usually means cold emails, DMs, and guesswork on both sides. DirectCollab removes that hassle with a platform designed around how creators and brands actually need to connect.

How it works

Dual Sign-Up (Creator / Brand) ↓ Role-Based Profile Setup ↓ Matching Engine ↓ Direct Collaboration — No Cold Emails

Key features

  • Dual sign-up mode for Creators and Brands
  • Role-based matching system
  • Eliminates cold outreach between both sides
  • Streamlined collaboration workflow

What I'm learning

  • Designing role-based user flows and permissions
  • Structuring a matching system between two user types
  • Planning a full-stack app beyond a single-page project
  • Thinking through platform-level product design
